# Escritório dos Agentes

Escritório virtual em pixel art onde cada personagem é uma automação real (render de criativos, downloads do TikTok, minerador de bases).

A página é estática (GitHub Pages). Para executar tarefas ela conversa com o servidor local `escritorio/server.py` do repo criativo-gen, em `http://localhost:8765`, que precisa estar rodando no Mac (`~/bin/escritorio.sh`). Sem o servidor, mostra o escritório em modo demonstração.

Outro endereço de servidor: `?api=http://ip:8765`.
